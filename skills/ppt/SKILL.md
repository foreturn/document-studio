# PowerPoint 演示文稿

以可编辑的演示文件完成用户任务。本技能提供工作流、参考和素材，不绑定本地脚本、运行时、指定插件或服务。资源路径均相对于本技能目录。

## 选择可用能力

先检查当前会话实际可调用的文档制作、文件读写、转换和渲染能力，再选择执行方式。已有宿主工具、连接器或原生编辑能力可直接使用，沿用其文件操作与授权边界。
不要假定其他插件已安装，不要求预装本地开发环境，也不为普通文档任务自动安装依赖。读取、创建、编辑、导出和渲染是不同能力，不能仅因工具名称包含“文档”就假定全部支持。
默认交付可编辑的 `.pptx`；用户明确要求 HTML 才交付 HTML。若宿主只有文本能力，交付清楚标明的页面文案或大纲，并说明当前无法生成真实 PPTX；不得声称已经创建文件，不得以改后缀代替生成。

## 规划与创作

- 从请求确定受众、目的、篇幅、事实来源、交付路径及模板。简短需求可说明合理假设；不虚构数据、客户或引用。
- 每页明确核心结论及承接关系。问题解决型叙事可按需参考 [叙事框架](references/storyline-framework.md)，页数与结构服从用户需求。
- 沿用用户模板和品牌；无指定时采用 16:9、清楚的标题层级和适当留白。内容过多时精炼或拆页，不能仅缩小字体。
- [PPTX 内容示例](assets/sample-presentation.json) 与 [字段说明](references/pptx-input.md) 供组织内容；将字段映射至所选工具的实际接口，不假定工具直接接受此 JSON。
- 配图应支持论点。按需使用宿主已有的图片生成、素材或绘图能力，参考 [配图指引](references/image-prompt-engineering.md)；无法获取素材时说明并采用文字或简单图形，不把提示词当作已生成图片。

## 编辑现有演示

检查完整文件，定位目标页面、对象和受影响的模板元素。使用当前可用且能保留原文件结构的编辑能力，只修改目标内容，另存结果。创建工具不等于编辑工具，不能用重建代替未经同意的保真编辑。
复杂母版、SmartArt、媒体和动画须确认工具实际支持；若不能可靠保留，说明具体影响并提供可行选择。无法读取文件时，不凭文件名猜测内容。

## HTML 模式

可按用户要求使用 [页面模板](assets/deck-template.html)，替换其中 DECK_TITLE、TOTAL_SLIDES、SLIDES_HTML 占位内容。转义用户文字，核对图片资源与翻页行为。模板包含浏览器端样式与交互，依赖外部 CDN，离线交付须处理资源。
[HTML 内容样例](assets/sample-deck.json) 与 [数据结构](assets/deck-schema.json) 仅供编排参考；样例中的指标是演示文案，不能当作已证实事实。视觉按需读 [视觉与动效](references/visual-design-system.md)，不要把浏览器动画宣称为原生 PowerPoint 动画。

## 验证与交付

使用宿主已有能力重新打开输出，核对页数、文本、图片与备注。若可渲染，逐页检查遮挡、裁切、换行与字体；若只能检查结构，明确说明视觉未验收。
返回实际可访问的文件链接及关键限制。仅完成文案时明确标注为大纲；内容语气服从受众要求，不插入代理角色、内部规划或检查记录。
