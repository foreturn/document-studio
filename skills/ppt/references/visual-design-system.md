# 视觉与动效

沿用用户模板和品牌。没有指定时采用明确的字体层级、统一色盘、稳定边距和适度留白。文字与背景应有足够对比；内容过密时先精炼或拆页。图表、图片和简单图形应帮助理解，不为装饰而增加密度。

HTML 可使用缓动转场、适量阶梯入场与进度反馈，避免影响阅读和键盘导航。尊重宿主预览及浏览器的实际能力；浏览器动效不能当作 PowerPoint 原生动画交付。

最终检查遮挡、超边界、换行、字体及图片裁切。结构正确不代表视觉正确；没有渲染能力时如实标注。

# 科技感设计系统与一句话生成法则

当用户仅给出一句话需求且要求“科技感强烈”时，按以下美学规范与结构法则自动升维：

- **色彩矩阵（Dark Cyber Palette）**：底色以深空黑（`#030712` / `slate-950`）为基底，营造沉浸式暗黑数字终端质感；主色采用荧光青/赛博蓝（`#00F0FF` / `cyan-400`）传达量子光流与高科技算力；辅色采用电光紫（`#A855F7` / `purple-500`）与钛金属冷灰（`#94A3B8` / `slate-400`）形成光影对比；强调色采用脉冲琥珀（`#F59E0B` / `amber-400`）突出关键告警与突破点。
- **版式与卡片（HUD & Glassmorphism）**：采用 HUD 抬头显示器风格与微透玻璃拟态卡片，外描边带微光（`border border-cyan-500/20`、微发光投影）；数据指标大字突出（Hero Metrics），配以单位与微型进度条，增强数字化说服力。
- **一句话叙事升维（Five-Act Tech Narrative）**：将简短的一句话主题解构为五幕科技叙事：01 破晓/现状（宏观天堑与行业挑战）、02 破局/内核（技术范式与核心架构突破）、03 演进/矩阵（产品能力与系统拓扑解构）、04 落地/实证（硬核指标验证与落地收益）、05 远景/纪元（未来生态演化与行动倡议）。每页提炼科技感 Tag（如 `CORE BREAKTHROUGH`、`QUANTUM LEAP`、`DATA HORIZON`）。
- **科技感配图意象**：配图提示词聚焦于全息投影、量子电路、神经网络光纤、暗色数字孪生机房、冷光玻璃曲面等，避免低质卡通或陈旧商务夹克插图。

## 科技感三大细分子风格（Tech Sub-styles）

根据受众与业务场景，提示词可显式选用以下细分子风格：

1. **深色赛博（Dark Cyber）**：
   - 特征：深空黑底（`#030712`）、荧光青光效（`#00F0FF`）、电光紫渐变（`#A855F7`）、微透玻璃拟态卡片与呼吸发光边框。
   - 适用场景：AI大模型、前沿算力芯片、智能网联车、颠覆性技术发布会与创投路演。

2. **极客钛冷（Titanium Clean）**：
   - 特征：冷钛灰白或暗钛冷灰底、深海军蓝沉稳字、拉丝金属微质感、极简几何细线微卡片与高对比度数据条。
   - 适用场景：国家重点实验室、大厂技术架构评审、硬核安全合规、工程实施白皮书汇报。

3. **新便当网格（Neo-Bento Grid）**：
   - 特征：模块化网格卡片分区、HUD 仪表盘数字插槽、胶囊状科技 Tag、高对比度黑白灰底色配单一点缀霓虹色。
   - 适用场景：开发者大会、SaaS产品矩阵发布、数字化运营看板与实时监控复盘。

## 科技排版负面戒律（Negative Design Constraints）

- **戒大段密集文字**：单页文本块不超过 3 行，拒绝将汇报材料退化为演讲提词板；核心观点用“短句+大字关键词”呈现。
- **戒老旧商务剪贴画**：严禁使用握手小人、灯泡拼图、低质齿轮等陈旧素材；配图必须遵循专业全息/流光/数字孪生规范。
- **戒色彩繁乱失控**：整套演示限定 1 个主基调（深黑/冷灰）+ 1 个发光主色（青/蓝）+ 1 个告警/突破强调色（琥珀/紫），杜绝五颜六色。
- **戒凭空捏造背书**：演示数据与行业基准必须标明测算模型或假定范围，禁止臆造未经核实的真实客户评价或商业合作。

# 演示动效体系：转场与内容页逐级动效（Motion & Animation System）

科技感演示的精髓在于“静若处子，动若脱兔”。全篇动效分为幻灯片间的**转场动效（Slide Transitions）**与页面内部组件的**逐级入场动效（In-Slide Staggered Animations）**。

## 1. 幻灯片转场动效（Slide Transitions）

每页幻灯片之间必须具备丝滑连贯的换页节奏，严禁生硬切页：

- **平滑淡出（Fade / Apple Spring）**：
  - 效果：旧页平滑隐退，新页伴随轻微弹性缩放（`scale(0.96) -> scale(1)`）优雅显现。
  - 适用：全篇默认转场，尤其适用于背景与章节的平稳推进。
  - 参数：时长 0.5s~0.6s，缓动曲线 `cubic-bezier(0.16, 1, 0.3, 1)`。
- **景深穿梭（Depth-Scale / 3D Zoom）**：
  - 效果：画面自暗夜深处向观众眼帘层层推进放大，营造跨越算力维度的穿梭感。
  - 适用：第 2 页“破局·量子跃迁”与突破性架构发布，带来强烈视觉冲击。
- **视差滑移（Parallax Slide）**：
  - 效果：前景文本卡片与背景全息粒子以差异化速度横向滑移。
  - 适用：第 3 页“系统拓扑”与模块分层演化，彰显工程空间感。

## 2. 内容页元素逐级入场动效（In-Slide Staggered Choreography）

单页内部各元素严禁“轰然同时全盘弹出”，必须按认知逻辑实施阶梯式逐级绽放：

- **第一阶段 · 定焦（0 ~ 100ms）**：
  - 顶栏 Tag（`[01 · MACRO HORIZON]`）与动作大标题率先快速淡入（`anim-stagger-1`），观众视线瞬间锁定核心论点。
- **第二阶段 · 导引（100 ~ 200ms）**：
  - 导引段落或痛点陈述自下微浮入场（`translateY(16px) -> 0`，`anim-stagger-2`），展开逻辑铺垫。
- **第三阶段 · 展开（200 ~ 450ms）**：
  - 2~3 个结构化卡片容器依次错落入场（`anim-stagger-3`、`anim-stagger-4`），如齿轮咬合般连贯排布，引导思维层次。
- **第四阶段 · 爆发（450 ~ 700ms）**：
  - Hero Metrics 量化大字启动**数字滚动缓动动画（Counter Tweening）**：从 0 毫秒级飙升至真实目标数值（如 `< 1.2μs`、`380%`），搭配微弱荧光脉冲（`pulseGlow`），形成强烈心理震撼。
- **第五阶段 · 氛围（常驻呼吸态）**：
  - 全息配图保持缓慢运镜缩放（`Ken Burns Effect`，18s 周期无缝微推移）；背景暗夜光斑缓慢呼吸流动，营造活体数字空间。

## 3. 宿主实现规范与交付说明

- **原生 PPTX 模式**：优先映射为 PPTX 页面切换效果（平滑、淡出、推入）与形状动画窗格（淡入、自底部飞入、擦除）；若宿主工具仅支持静态文本框，须在备注页（Notes）标明该页转场与逐级入场设计方案。
- **交互式 HTML 模式**：通过 CSS 类名全量落地，页面使用 `.slide.active`，内部元素分别挂载 `.anim-stagger-1` 至 `.anim-stagger-5`，数值处挂载 `.counter-num[data-target][data-decimals]`，并在换页时触发 JavaScript 重播。
