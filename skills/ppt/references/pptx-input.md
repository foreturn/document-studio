# 自由发散式演示排版与组件设计参考

本参考阐明在摒弃死板机械模板的前提下，如何根据特定主题自由发散构思、动态组织多元科技感页面。大模型应根据每页的核心职能与论据类型，自主选择并设计最贴合的版式构图，再映射至当前宿主工具的实际能力。

## 多元页面版式原型（Dynamic Layout Archetypes）

坚决拒绝千篇一律的单一左右对称分栏，大模型可根据页面具体职责灵活选用以下六大版式原型进行自由创造与混搭：

1. **全屏沉浸大视觉型（Hero Immersion）**：
   - 构图结构：全景深邃暗夜/流光微光底图，居中或左侧排布超大号颠覆性动作标题、一行极简洞察金句与极客胶囊 Tag。
   - 适配场景：封面序章、重大突破里程碑、全篇高潮升华。

2. **多维动态便当盒型（Dynamic Bento Grid）**：
   - 构图结构：打破死板规整表格，采用 2~4 个不同长宽比例的微透拟态玻璃卡片进行不对等自由拼接（如主卡展示关键架构，两张次卡分别承载核心优势与参数）。
   - 适配场景：平台能力矩阵、核心特性全景、多维度亮点呈现。

3. **分层架构拓扑型（Layered Architecture Flow）**：
   - 构图结构：纵向四层解耦阶梯（接入层-控制层-计算引擎-数据基础设施）或横向端到端流水线，节点间以发光拓扑连线示意协同机理。
   - 适配场景：系统架构解构、算法流式机理、工程拓扑总览。

4. **极客数据罗盘型（Multi-Metric HUD Compass）**：
   - 构图结构：以 2~4 个 Hero Metrics 量化大字指标卡为核心枢纽，环绕微型进度条、对比差值条与极简解读标签。
   - 适配场景：硬核基准跑分、性能实测倍率、ROI 商业价值证明。

5. **双向反差对比型（Split Comparison）**：
   - 构图结构：左右或上下采用高对比色块强力对冲（一侧冷灰/暗红标明传统旧范式痛点，一侧荧光青/电光紫标明全新跃迁方案），形成戏剧化张力。
   - 适配场景：传统方案 vs 创新破局、痛点与解法深度对比。

6. **时空脉冲演进型（Timeline & Milestone Flow）**：
   - 构图结构：横向流动光轨时间轴，串联起发光的阶段性演进里程碑节点。
   - 适配场景：技术演化路线图、未来生态战略演进。

## 科技感组件在 PPTX 形状中的映射规范

- **顶栏徽标（Tag / Kicker）**：映射为页面顶部小号文本框或微型圆角矩形，字号 10~12pt，全大写英文字符配微冷灰或荧光青（如 `[01 · MACRO HORIZON]`）。
- **动作型标题（Action Title）**：映射为页面主标题占位符，字号 22~28pt 加粗，亮白（`#FFFFFF`）或冰蓝（`#E0F2FE`），直接亮出观点短句。
- **导引论述（Lead Content）**：映射为副标题或观点段落，字号 13~15pt，微冷灰（`#94A3B8`），铺陈技术机理或背景。
- **分栏卡片（Cards / Bento Boxes）**：映射为 2~3 个深色填充、带浅色细边框的独立矩形形状容器，承载短句与高亮关键词。
- **量化指标卡（Hero Metrics）**：映射为独立的大字突出卡片，数值采用 32~40pt 加粗等宽字体，配小号单位与指标说明。
- **全息配图（Image Placement）**：右侧、局部或全屏底图布局，遵循 [配图提示词工程规范](image-prompt-engineering.md) 指导生成并插入图片。
- **演说台本（Speaker Notes）**：写入 PPTX 备注页，详细记录演讲提示、深度架构背景与真实防幻觉出处。

## 页面转场与页内动效映射规约

- **幻灯片转场（Slide Transition）**：按页面情绪选用 `fade`（平滑淡出）、`push`（推入）、`morph`（平滑切换）或 `zoom`（缩放）。
- **页内逐级动效（In-Slide Animation）**：按认知顺序规划动画序列（1 标题定焦 -> 2 导引浮入 -> 3 卡片阶梯呈现 -> 4 数据大字滚动递增）。
- **工具映射策略**：具备完整动画支持的工具直接写入动画窗格；静态工具则在备注页完整保留动效设计时序供用户直接套用。
