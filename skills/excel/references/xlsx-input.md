# 工作簿数据结构参考

[sample-workbook.json](../assets/sample-workbook.json) 用于整理 sheets：每表包含 name、columns、rows，可选 widths。表名须符合 Excel 规则且大小写不重复，行宽应与列数一致。实际操作需映射至宿主工具接口。

单元格可为文本、有限数值、布尔值或空值；对象 value 与 number_format 表示数值及格式，formula 表示明确要求写入的公式，不同时提供 value 和 formula。以等号开头的普通文本仍是文本。

预算样例的金额单位为元，12000 与 3000 的独立核对合计为 15000。此结果用于验证样例，不能据此宣称工作簿公式已由计算引擎重新计算。

# 科技感数据驾驶舱与一句话构建法则

当接收到一句话生成科技感数据报表或看板需求时，按以下规范组织工作簿：

- **结构与分工**：采用“驾驶舱看板（Dashboard）+ 明细矩阵（Data Matrix）+ 系统参数（Config）”三层工作表结构。
- **深色与冷调配色**：看板表采用现代科技深色或冷灰蓝基调，表头采用深海军蓝（`#0F172A`）底纹配亮白文字，网格线使用微弱冷色。
- **KPI 核心卡片**：在看板首屏顶部布置 3~4 个核心 KPI 卡片（大字指标值 + 环比公式 + 状态指示），关键计算通过公式联动明细表，不填充虚假硬编码数字。
