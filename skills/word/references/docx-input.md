# 科技白皮书排版规范与一句话排版法则

当接收到一句话生成科技方案或白皮书需求时，按以下规范组织排版：

- **封面与层级**：采用现代科技封面风格，页眉保留密级/版本标签；主标题使用冷钛色或科技蓝，正文采用高对比现代无衬线中英文排版。
- **模块高亮卡片（Callout Cards）**：重要架构结论、核心创新点采用带左侧科技蓝单色粗边框与浅冷色底纹的单单元格卡片承载，凸显技术分量。
- **技术拓扑与数据矩阵**：方案架构按“接入层-服务层-计算/模型层-基础设施层”结构化排版；对比表格采用三线矩阵式表格，表头使用科技深色填充底纹与白色文字。
